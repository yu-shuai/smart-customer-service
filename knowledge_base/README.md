# 知识库使用说明（先读这个，再上传）

这套文件是给 `rag_llm_server` 的语音课程顾问「余小智」用的知识库底稿。
检索链路：`main.py /api/chat_callback` → `services/rag_service.py` → 火山知识库集合 `dw_ai` → 拼进 system prompt → Ark LLM 流式输出。

## 怎么上传到火山知识库

1. 控制台创建知识库集合，名称与 `.env` 对齐：`KB_COLLECTION_NAME=dw_ai`、`KB_PROJECT_NAME=default`。
2. `.env` 里确认 `VOLC_ACCOUNT_ID`（主账号 ID，`V-Account-Id` 必填）。
3. 把这 8 个 md 文件作为文档上传，**一个文件一个主题，不要合并成一个大文件**。
4. 切片建议：默认自动切片即可，单个切片控制在 300-800 字。

## 上传后怎么验证

```bash
# 起服务
python main.py
# 单测检索（不用等语音链路）
curl "http://127.0.0.1:3001/debug/rag?query=就业班多少钱"
```

看返回的 `retrieved_context` 是不是命中了 `02` 号文件里的价格段。
控制台日志会打印 `✅ [RagService] 成功提取 N 条知识内容`，如果是 `⚠️ 未检索到匹配的知识内容`，说明知识库没开通或集合名不对。

## ⚠️ 上线前必须替换的清单

以下全是**示例占位数据**，不改就对外用，等于让 AI 当众编数字：

1. **价格**：4 门课的原价 / 早鸟价（出现在 `01`、`02`、`06`）。
2. **联系方式**：微信 `dw-ai-001`、电话 `400-000-0000`（出现在 `00`、`02`、`07`）。
3. **学员案例**：`04` 里三个案例全是编的，必须换成真实且**已获书面授权**的故事，姓名用代称。
4. **服务 SLA**：`03` 里的答疑响应时长、回放有效期、重修次数、班级规模。
5. **退费政策**：`07` 目前只有口径没有具体条款，需补真实协议规则（开课前 / 开课后的比例）。
6. **优惠规则**：`02` 里的老学员折扣、团报减免、专项减免额度。

## 命名口径（改名字时必须一起改）

| 位置 | 内容 |
| --- | --- |
| 机构名 | **余帅 AI 教育** |
| 顾问（AI 人设） | **余小智** |
| 老板 / 主讲 | **余帅老师** |

这三个称呼分散在 **8 个 md 文件 + 2 个 py 文件**里，改任何一个都要全量替换：

- `knowledge_base/*.md` —— 全部 8 个文件
- `rag_llm_server/services/llm_service.py` 第 29 行 —— system prompt 里的人设与老板称呼
- `rag_llm_server/main.py` 第 160 行 —— `WelcomeMessage`（AI 开口第一句，用户最先听到的名字）

漏改的后果：AI 前一句自称 A、后一句自称 B，用户当场就知道这是拼出来的。

## 已顺手修掉的两个坑（2026-09-17）

1. `services/rag_service.py` 原来用 `json=body` 发请求，httpx 会重新序列化（加空格、中文转 `\uXXXX`），与签名字节不一致，火山返回 `403 / 1000001 check sign not match`。已改为 `content=signer.body_str.encode("utf-8")`，与 `main.py` 的写法一致。
2. `limit` 从 1 改成 3。原来只召回 1 条切片，问"就业班多少钱"这类问题很容易漏掉价格文件。

## 还没解决的阻塞

当前账号调用知识库接口返回 **`403 / 300001 您还没有下单，请前往火山引擎官网下单`**，即知识库服务未开通。
表现是 `retrieve()` 只打印一行就返回空字符串，LLM 走"知识库没更新"的拦截话术 —— **看起来像知识库配错了，其实是服务没买**。开通后无需改代码。
