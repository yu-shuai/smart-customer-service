# 余帅 AI 教育 · 课程体系（示例数据，上线前替换）

## AI 大模型应用开发 · 就业班（王牌课）

**适合谁**：想转行做 AI 应用开发的人。零基础可入，但要求每天能投入 2 小时以上，能坚持 6 个月。

**学多久**：6 个月，直播 + 录播 + 每周项目评审。

**学什么**：

1. Python 工程基础与 Git 协作（4 周）
2. 大模型 API 调用与 Prompt 工程（3 周）
3. RAG 检索增强生成：向量库、切片、召回、重排（5 周）
4. Agent 智能体开发：工具调用、多轮编排、Function Calling（5 周）
5. 模型微调与评测（4 周）
6. 工程化上线：FastAPI、Docker、监控、成本控制（4 周）
7. 毕业项目：从 0 到 1 交付一个可上线的 AI 应用（3 周）

**学完能做什么**：独立承接 AI 应用开发需求，能独立搭一套企业知识库问答 / 智能客服 / AI Agent 系统。

**毕业产出**：3 个可写进简历的完整项目 + 1 个部署在线的毕业设计。

**价格**：12980 元，早鸟价 9980 元（示例价，需替换）。支持分期。

**一句话**：这是余帅唯一敢说"学完能找工作"的课，也是最累的一门。
