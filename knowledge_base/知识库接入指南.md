# 火山知识库接入指南（rag_llm_server）

知识库已经在控制台建好了，接入只需要 **4 步**：取值 → 传文档 → 填 .env → 验证。

---

## 第 1 步：拿到三个值

打开知识库列表：
<https://console.volcengine.com/vikingdb/knowledge/region:vdb-knowledge+cn-beijing/collection/list>

| 要填的字段 | 在哪看 | 样子 |
| --- | --- | --- |
| `KB_COLLECTION_NAME` | 知识库列表里的集合**名称**列 | 纯英文/数字，如 `dw_ai` |
| `VOLC_ACCOUNT_ID` | 控制台右上角「账号 → 账号信息 → **主账号 ID**」 | `21xxxxxx` 或 `kb-xxxx` 形式 |
| `KB_PROJECT_NAME` | 一般就是 `default`，不用改 | `default` |

⚠️ 集合名填**名称**那一列，不要填中文显示名，也不要填集合 ID。填错的表现是检索一直返回空，控制台会打印 `not found`。

---

## 第 2 步：把知识库文档传上去

上传 `knowledge_base/` 下的 **8 个 md 文件**（一个文件一个主题，别合并成一个）：

```
00_总纲_机构介绍与回答规范.md
01_课程体系与适合人群.md
02_价格_优惠_报名与付款.md
03_上课方式_服务与学习保障.md
04_就业方向与学员案例.md
05_常见异议应对话术.md
06_高频问答FAQ_语音短答版.md
07_敏感问题_退费_投诉与转人工.md
```

**切片建议**（控制台 → 知识库 → 文档处理策略）：

- 切片最大长度设 **300-500**，不要用默认的 2000。
  - 我们的内容是 FAQ / 话术型，信息密度大、上下文关联小，切片越小越准。
  - 用 2000 会把「价格」「异议话术」几个主题揉进一个切片，问 A 召回到 B。
- 解析方式选「通用解析」，开启图片 OCR 无所谓（我们没图）。

传完在控制台点【知识检索】试一句 `就业班多少钱`，能看到命中 `02` 号文件的价格段，说明文档侧没问题。

---

## 第 3 步：填 `.env`，重启服务

`rag_llm_server/.env` 末尾已经有了这三行，把值换成你自己的：

```bash
VOLC_ACCOUNT_ID=你的主账号ID
KB_COLLECTION_NAME=你的集合名
KB_PROJECT_NAME=default
```

另外确认这两项在（之前已配好）：

```bash
VOLC_ACCESS_KEY=...
VOLC_SECRET_KEY=...
```

**改完必须重启服务**，`.env` 只在启动时读一次：

```bash
cd rag_llm_server
./.venv/Scripts/python.exe main.py
```

启动日志里现在会打印一行配置自检，先看这行对不对：

```
📚 [RagService] 知识库配置: collection=dw_ai project=default account_id=kb-xxxx ak=已配置
```

如果 `collection=(空!)` 或 `account_id=(空!)`，说明 `.env` 没读到——检查是不是改完没重启，或者变量名拼错。

---

## 第 4 步：验证（不用跑语音链路）

```bash
curl "http://127.0.0.1:3001/debug/rag?query=就业班多少钱"
```

- **成功**：返回 `retrieved_context` 里有价格内容，控制台打印 `✅ [RagService] 成功提取 3 条知识内容`。
- **失败**：看控制台打印，对照下面的排错表。

再看端到端（走 LLM，返回完整回答）：

```bash
curl -X POST http://127.0.0.1:3001/debug/chat \
  -H "Content-Type: application/json" \
  -d '{"question":"就业班多少钱","history":[]}'
```

---

## 排错表

| 控制台打印 | 原因 | 怎么修 |
| --- | --- | --- |
| `⚠️ 未检索到匹配的知识内容` | 集合名错 / 文档还在解析中 | 等文档解析完成；核对 `KB_COLLECTION_NAME` |
| `403 ... 300001 您还没有下单` | 知识库服务未开通 | 控制台开通知识库服务，代码不用改 |
| `403 ... 1000001 check sign not match` | 签名不对 | 查 AK/SK、`VOLC_ACCOUNT_ID` 是否主账号 ID |
| `... not found` | 集合不存在 | 核对集合名大小写、有没有多余空格 |
| 返回空但没任何报错 | `except` 吞异常 | 看有没有 `❌ [RagService] 异常` 那行 |

---

## 验证通过后，跑语音链路

1. 起 `rag_llm_server`（端口 3001）。
2. 前端 `npm start`，进「自定义助手」房间。
3. AI 开口第一句是 `WelcomeMessage`（`main.py` 第 160 行）：「我是余小智，你的专属课程顾问……」。
4. 问一句「就业班多少钱」，AI 应该用知识库里的价格回答，而不是说「库里没更新」。

**注意**：如果 AI 回答的是「抱歉，这块信息库还没更新」，那就是 RAG 没召回，回到第 4 步查，别去改 prompt。
